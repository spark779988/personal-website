# DS Arena

数据结构期中冲刺网页题库，使用纯前端 HTML/CSS/JavaScript 构建，无需后端或构建工具。

## 功能

- 4 个原始题库分类入口
- 第 1、2、3 章单元检测
- 20 道选择 + 10 道填空 + 3 道代码的章节均衡综合卷
- 仅客观题模式
- “重点 / 有疑惑”标记与标记题专项练习
- 客观题自动判分、逐题答案解析和知识点
- 代码题参考作答与自评
- 错题重做
- 本地持久化题目标记

## 本地预览

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。

## EdgeOne Makers 部署

1. 将本目录推送至 Git 仓库的一个独立分支。
2. 在 EdgeOne Makers 中导入 Git 仓库。
3. 项目根目录选择本目录；没有构建命令，构建输出目录为 `.`。
4. 加速区域选择“全球可用区（不含中国大陆）”。
5. 部署完成后使用平台生成的预览网址。

页面没有第三方 CDN、字体、图片或后端依赖，适合直接进行全球静态加速。
